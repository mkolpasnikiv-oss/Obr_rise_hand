# Hand Raise — Заявки игроков для Owlbear Rodeo

Расширение для Owlbear Rodeo 2. Игрок нажимает «Поднять руку», мастер сразу видит имя игрока и может закрыть заявку кнопкой «Готово». Игрок может сам опустить руку.

## Файлы
- `manifest.json` — манифест расширения Owlbear.
- `index.html`, `style.css`, `app.js` — интерфейс и логика.

## Важно: публикация
Owlbear загружает расширения по HTTPS-ссылке на `manifest.json`. ZIP-архив нельзя просто импортировать в комнату. Сначала разместите содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages), затем добавьте URL опубликованного `manifest.json` в профиль Owlbear.

## Размещение на GitHub Pages
1. Создайте репозиторий GitHub, например `owlbear-hand-raise`.
2. Загрузите в корень репозитория все четыре файла из архива, сохранив структуру.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Дождитесь публикации сайта. URL манифеста будет иметь вид:
   `https://ВАШ-ЛОГИН.github.io/owlbear-hand-raise/manifest.json`
   Подставьте свой логин и имя репозитория. Убедитесь, что ссылка открывается в браузере и показывает JSON.

## Установка в Owlbear Rodeo
1. Войдите в Owlbear Rodeo.
2. Откройте профиль и выберите **Add Extension** (в некоторых версиях интерфейса: **Extras → Extensions → +**).
3. Вставьте полный HTTPS URL опубликованного `manifest.json`.
4. Подтвердите добавление расширения.
5. Откройте существующую комнату и включите расширение в менеджере расширений комнаты. Для новой комнаты выберите его при создании.
6. Мастер и игроки должны использовать одну и ту же комнату и включить расширение.
7. Нажмите значок расширения в верхней части интерфейса. Игрок увидит кнопку поднятия руки, мастер — очередь заявок.

## Проверка
1. Откройте комнату в двух браузерах/профилях: один как мастер, другой как игрок.
2. В окне игрока нажмите «Поднять руку».
3. В окне мастера должна появиться карточка с именем игрока.
4. Нажмите «Готово» у карточки: заявка исчезнет, а у игрока рука опустится.
5. Проверьте также самостоятельную отмену игроком.

## Особенности и ограничения
- Передача событий выполняется через `OBR.broadcast` SDK Owlbear Rodeo; отдельный сервер не требуется.
- Очередь намеренно временная: если мастер перезагрузит расширение или отключится, уже показанные заявки не восстанавливаются. Новые сообщения продолжают поступать после подключения.
- Если один пользователь вошёл в комнату с нескольких устройств/вкладок, интерфейс трактует их как одного игрока по ID пользователя.
- Имя отправителя берётся из SDK Owlbear; как и любой клиентский сигнал, это не является механизмом безопасности или подтверждением личности.
- `app.js` загружает SDK с CDN `esm.sh`; для работы требуется доступ браузера к этому домену.
